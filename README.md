# 专升本三科题库 · SCGS 学习平台

四川统招专升本备考题库与错题本。以 Markdown 为**唯一数据源**，驱动三科刷题、错题复习与单词翻卡。

## 🔗 在线访问（GitHub Pages）

点击直达：[专升本学习平台](https://cheshiping.github.io/College-to-university-exam-question-bank/)

> 推送 `main` 分支即可自动重新部署，无需手动操作。

## 📖 项目介绍

- **三科题库**：计算机 / 高等数学 / 英语，每科一个 `题库.md` + 生成的交互 `题库页.html`。
  - 高数支持 LaTeX 公式（行内 `$...$`、块级 `$$...$$`）。
  - 题目带「答案 + 解析 + 来源」，做错可一键入篮存入错题本。
- **错题本**：三科 `错题集/错题本.md` 为个人刷题数据（与站点解耦、不入库、不公开），配套交互 `复习页.html`。
- **英语单词**：`单词本` / `生词本` / `单词卡` 翻卡记忆。
- **共建题库**：页面底部「投稿题目」可将新题提交给站长审核入库。

目录结构：

```
SCGSstudy/              站点总目录（入口 index.html、manifest、图标、投稿页、KaTeX、构建器）
计算机/  题库.md 题库页.html 错题集/
高数/    题库.md 题库页.html 错题集/
英语/    题库.md 题库页.html 错题集/（含单词本/生词本/单词卡）
真题收集/               历年真题资料
AGENTS.md              仓库工作约束（给编码 Agent 读）
```

## ➕ 扩展题库方式

题库只有一处数据源：各科 `题库.md`（`.html` 是构建产物，**不要手改 HTML**）。两种方式：

### 方式一：直接改数据源（推荐）

在对应科目的 `题库.md` 里，按下面格式追加题目：

```markdown
## 专题·章节

**真题-高数-单选-009.** 题干内容（数学公式用 $...$）
- A. xx　B. xx　C. xx　D. xx
- **答案：B**　解析：解题思路与依据。
- 来源：2023 四川专升本真题（尽量精确到省/年）
```

- 分节用 `## 章节`；无选项的题型不写「选项」行。
- **真题例题请尽量标注真实来源（省 + 年份）**，不要随手乱编。

改完后，重新生成对应的 `题库页.html` 即可刷新站点。

### 方式二：交给助手重新生成

运行站点构建器刷新页面：

```powershell
# 在 SCGSstudy 目录
python build.py        # 一次生成三科题库页 / 复习页 / 单词页
```

也可以直接告诉编程助手「按 XX 章节出 N 道题并写入 题库.md、重新生成题库页」，由助手代跑并校验（见 `AGENTS.md`）。

### 方式三：网页投稿

打开站点 → 右下角「📮 投稿题目」→ 上传图片或手动填写 → 提交给站长审核后再入库。
